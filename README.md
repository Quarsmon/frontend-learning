# Kişisel Tanıtım Sayfam

Frontend geliştirme öğrenme sürecimin ilk projesi. HTML ve CSS kullanarak yapılmış basit bir kişisel tanıtım sayfası.

## Kullanılan Teknolojiler
- HTML5
- CSS3

## Nasıl Çalıştırılır
1. Bu repoyu klonla
2. `index.html` dosyasını tarayıcıda aç (veya VS Code'da Live Server ile aç)

## Neler Var
- Semantic HTML yapısı (header, nav, main, section, footer)
- İletişim formu
- Temel CSS stilleri (renkler, Box Model, selector'lar)
